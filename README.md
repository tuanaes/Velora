# Velora Web v0.1

Первый интерактивный прототип платформы AI-персонажей.

## Запуск
Можно открыть `index.html` в браузере.
Для публикации удобно загрузить `index.html` в GitHub и подключить репозиторий к Vercel.

## Сейчас есть
- Главная
- каталог / Explore
- карточки персонажей
- поиск
- профиль
- демо-чат
- мобильная нижняя навигация
- тёмный интерфейс Velora

AI, аккаунты, база данных и настоящий конструктор персонажей будут подключаться следующими этапами.


## v1.1.0 — исправление «Мои чаты»
- Список чатов читает только реальные поля таблицы `chats`/`characters` из `supabase-schema.sql`.
- Исправлено несовпадение `avatar/image_url` и `avatar_url`.
- Сортировка идёт по последнему сообщению, затем по `updated_at`/`created_at`.
- Ошибки Supabase теперь показываются прямо на странице вместо бесконечной загрузки.
